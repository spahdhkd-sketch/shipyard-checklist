## What Changed This Session

1. **Recovered truncated files (critical).** A previous "fable" model session left
   `assets/js/app-v2.js`, `assets/css/styles-v2.css`, and `sw.js` truncated mid-content
   (the app could not run). Restored the cut tails from the committed HEAD. All tests pass.
   - Root cause hint: on the Cowork virtiofs mount, the file-edit tools (Write/Edit)
     could silently truncate large files. **Workaround used: write via shell (bash) and
     re-verify with `node --check`.** Watch for this if editing big files again.
2. **WebP illustrations.** Converted 54 shipyard illustration PNGs to WebP twins
   (1214 KB -> 216 KB, ~82% smaller). `workVisual()` now serves them via
   `<picture>` (WebP source + PNG `<img>` fallback + existing line-icon error fallback).
   PNGs were kept (static-recovery test requires them). CSS: `.pictogram-picture{display:contents}`.
3. **Service worker = stale-while-revalidate** for CSS/JS (was network-first). Versioned
   `?v=ASSET_TOKEN` assets are effectively immutable, so cache is served instantly and
   revalidated in the background. Navigation stays network-first.
4. **Build tooling (artifacts not wired in yet).** `npm run build:assets` (tools/build-assets.mjs)
   minifies each JS/CSS 1:1 into `assets/dist/` WITHOUT bundling (preserves load order +
   globals). Measured ~26% size reduction (app-v2.js -24%, styles-v2.css -31%).
   `assets/dist/` is gitignored. **HTML/SW references were intentionally left unchanged.**
