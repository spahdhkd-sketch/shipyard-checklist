# GS 안전 체크리스트 웹페이지 사용설명서

- 대상 사이트: https://gs-safety-checklist.vercel.app
- 기준 버전: 0.5-20260525
- 작성일: 2026-05-25
- 대상 사용자: 현장 작업자, 조장, 총무/관리자

## 1. 기본 개념

GS 안전 체크리스트는 조선소 현장에서 작업 전 점검, 안전 서약, 불안전요소, 자재누락, 호선/작업자/푸시 알림을 한곳에서 관리하는 웹앱입니다.

주요 데이터는 Supabase 서버와 동기화됩니다. 같은 계정/작업자로 접속하면 PC, 모바일, 다른 브라우저에서도 동일한 원격 데이터를 기준으로 화면이 정리됩니다.

## 2. 권한 구분

### 작업자

- 본인 사번으로 로그인합니다.
- 작업 전 점검을 작성하고 제출합니다.
- 불안전요소와 자재누락을 등록합니다.
- 본인 휴대폰/PC 브라우저 알림을 등록할 수 있습니다.

### 조장

- 작업자 기능을 모두 사용할 수 있습니다.
- 작업지시서 등록/관리 기능을 사용할 수 있습니다.
- 서약 미완료자 알림, 관리자 수동 푸시 등 발송 권한이 필요한 기능을 사용할 수 있습니다.

### 총무/관리

- 조장 권한과 동일하게 푸시 발송 권한을 가집니다.
- 관리자 모드에서 작업자, 푸시, 불안전요소, 자재누락 관리 기능을 사용할 수 있습니다.

### 관리자 수정 모드

- 화면 우측 상단 또는 관리 화면의 `수정` 토글을 켭니다.
- 관리자 비밀번호 확인 후 수정 모드가 켜집니다.
- 작업자 추가/삭제, 호선 수정, 항목 수정, 이력 초기화, 알림 기기 관리 등 수정 기능이 활성화됩니다.
- 푸시 발송은 관리자 수정 모드만으로는 부족하며, 로그인 작업자가 조장/총무/관리 권한도 가져야 합니다.

## 3. 접속과 로그인

1. 사이트에 접속합니다.
2. 작업자 목록에서 본인 이름을 선택합니다.
3. 사번을 입력합니다.
4. 로그인이 완료되면 좌측 사이드바 또는 모바일 상단에 작업자 이름이 표시됩니다.
5. 로그아웃은 좌측 사이드바 또는 모바일 상단의 `로그아웃` 버튼을 사용합니다.

사번이 없거나 로그인이 되지 않는 경우 관리자에게 작업자 정보 등록 상태를 확인받습니다.

## 4. 동기화 상태 확인

좌측 사이드바 상단에 동기화 상태가 표시됩니다.

- `온라인`: 서버와 통신 가능한 상태입니다.
- `서버 확인 중`: 원격 상태를 확인 중입니다.
- `로컬 저장`: 일시적으로 서버 통신이 원활하지 않아 브라우저 저장소 기준으로 동작 중입니다.

동기화가 중요한 화면에서는 새로고침 후 좌측 상태가 온라인인지 먼저 확인합니다.

## 5. 브라우저 알림 등록

푸시 알림을 받으려면 각 작업자의 실제 휴대폰 또는 PC에서 알림 등록이 필요합니다.

1. 작업자 본인으로 로그인합니다.
2. 좌측 사이드바의 `휴대폰 알림 등록` 또는 `PC 알림 등록` 버튼을 누릅니다.
3. 브라우저 권한 팝업에서 알림을 허용합니다.
4. 등록이 완료되면 버튼이 `휴대폰 알림 등록됨` 또는 `PC 알림 등록됨` 상태로 바뀝니다.
5. 테스트가 필요한 경우 `테스트 알림` 버튼으로 현재 단말 수신 여부를 확인합니다.

주의사항:

- iPhone/Android는 브라우저와 OS 설정에서 알림이 허용되어야 합니다.
- 모바일에서는 사이트를 홈 화면에 추가해야 푸시가 안정적으로 동작하는 브라우저가 있습니다.
- 작업자별로 등록된 단말이 없으면 푸시 대상에 포함되어도 실제 수신되지 않습니다.

## 6. 홈

홈 화면은 전체 현장 상태를 빠르게 확인하는 대시보드입니다.

주요 영역:

- `작업 전 점검 시작`: 점검 화면으로 이동합니다.
- `불안전요소 등록`: 불안전요소 접수 화면으로 이동합니다.
- `자재누락 등록`: 자재누락 접수 화면으로 이동합니다.
- 오늘 점검 현황: 대기/호선/완료율을 표시합니다.
- 불안전요소/누락 자재/인도 예정: 현재 관리가 필요한 항목 수를 표시합니다.
- 공정 현황: 탑재, L/C, S/T, C/L, D/L 등 호선 공정 수를 표시합니다.

현장 작업자는 홈에서 오늘 해야 할 점검과 긴급 확인이 필요한 항목을 먼저 확인합니다.

## 7. 작업 전 점검

작업 전 점검은 작업지시서 기반 흐름과 직접 점검 흐름을 모두 지원합니다.

### 작업지시서 기반 점검

1. `작업 전 점검` 메뉴로 이동합니다.
2. 오늘 작업지시서 목록에서 본인이 포함된 작업을 선택합니다.
3. 작업지시서에 등록된 호선, 작업 유형, 공기구를 확인합니다.
4. STEP 2 공기구는 작업지시서 등록 공기구가 표시되며 선택은 잠겨 있습니다.
5. STEP 3 오늘 작업 호선은 작업지시서 호선과 일치합니다.
6. 안전 서약과 점검 항목을 완료합니다.
7. 제출하면 작업지시서 카드의 `점검 n/m명` 수치가 갱신됩니다.
8. 등록된 인원이 모두 제출하면 상태가 `점검 완료`로 변경됩니다.

### 직접 점검

1. 작업지시서가 없거나 즉시 점검이 필요한 경우 직접 작업 유형과 호선을 선택합니다.
2. 필요한 공기구와 점검 항목을 확인합니다.
3. 서약/점검 내용을 작성한 뒤 제출합니다.
4. 제출 후 점검 이력에서 확인할 수 있습니다.

## 8. 호선

호선 화면은 현재 등록된 호선과 공정 상태를 관리합니다.

일반 사용:

- 호선별 공정 상태를 확인합니다.
- 탑재, L/C, S/T, C/L, D/L 등 단계별 상태를 확인합니다.
- 검색/정렬을 통해 필요한 호선을 찾습니다.

관리자 수정 모드:

- 호선을 추가합니다.
- 공정 상태와 날짜 정보를 수정합니다.
- 호선 표시 순서를 저장합니다.
- 데스크톱에서는 호선 엑셀 내보내기/불러오기를 사용할 수 있습니다.

불안전요소 등록과 자재누락 등록의 호선 목록은 호선 화면에 추가된 호선을 기준으로 함께 반영됩니다.

## 9. 점검 이력

점검 이력 화면에서는 제출된 작업 전 점검 결과를 확인합니다.

주요 기능:

- 날짜/작업자/호선 기준으로 이력을 확인합니다.
- 상세 내용을 열어 점검 항목, 서약, 공기구, 제출 상태를 확인합니다.
- 관리자 수정 모드에서는 선택 삭제 또는 이력 초기화 기능을 사용할 수 있습니다.

주의사항:

- 이력 삭제/초기화는 복구가 어렵습니다.
- 삭제 전 필요한 이력은 별도로 내보내기 또는 캡처해 둡니다.

## 10. 빠른 메뉴

빠른 메뉴는 점검 항목과 작업 유형, 공기구, 픽토그램을 관리하는 설정 화면입니다.

일반 사용:

- 현재 등록된 작업 유형과 점검 항목을 확인합니다.
- 작업 유형별 공기구 지정 상태를 확인합니다.

관리자 수정 모드:

- 작업 유형을 추가/수정/삭제합니다.
- 섹션을 추가/수정/삭제합니다.
- 점검 항목을 추가/수정/삭제합니다.
- 공기구를 추가/수정/삭제합니다.
- 작업 유형별 사용 공기구를 지정합니다.
- 사용자 지정 픽토그램을 추가/수정/삭제합니다.

변경한 점검 항목은 이후 작업 전 점검 화면에 반영됩니다.

## 11. 서약

서약 화면은 오늘 작업자의 안전 서약 현황을 확인하고 미완료자에게 알림을 보내는 화면입니다.

주요 기능:

- 오늘 서약 현황 표를 확인합니다.
- 작업자별 서약 상태가 `완료` 또는 `미완료`로 표시됩니다.
- `미완료자 알림 발송` 버튼은 오늘 표에서 상태가 `미완료`인 작업자에게만 푸시를 보냅니다.
- `푸시 문구 수정` 버튼으로 미완료자 알림 제목/본문을 수정할 수 있습니다.

발송 조건:

- 대상 작업자가 브라우저 알림을 등록해야 실제 수신됩니다.
- 발송자는 조장/총무/관리 권한이 있어야 합니다.
- 권한이 없으면 서버에서 발송이 차단됩니다.

## 12. 통계

통계 화면은 점검과 접수 데이터를 요약해 보여줍니다.

확인 항목:

- 작업 전 점검 제출 흐름
- 작업자/호선 기준 상태
- 불안전요소 및 자재누락 추이
- 서약 현황

통계 수치는 앱에 동기화된 원격 데이터를 기준으로 표시됩니다. 숫자가 이상하면 먼저 동기화 상태와 필터 범위를 확인합니다.

## 13. 불안전요소 등록

현장에서 위험요소를 발견하면 불안전요소 등록 화면을 사용합니다.

등록 절차:

1. 홈 또는 메뉴에서 `불안전요소 등록`으로 이동합니다.
2. 호선을 선택합니다.
3. 불안전요소 내용을 작성합니다.
4. 필요한 경우 사진을 첨부합니다.
5. 확인 화면에서 내용을 검토한 뒤 제출합니다.

제출 후:

- 관리자 관리 화면의 불안전요소 목록에 즉시 접수됩니다.
- 등록 시 지정된 대상 작업자에게 불안전요소 푸시가 발송됩니다.
- 처리 상태는 관리 화면에서 변경할 수 있습니다.

## 14. 자재누락 등록

현장에서 자재 누락이 확인되면 자재누락 등록 화면을 사용합니다.

등록 절차:

1. 홈 또는 메뉴에서 `자재누락 등록`으로 이동합니다.
2. 호선을 선택합니다.
3. 누락 자재명과 내용을 입력합니다.
4. 필요한 경우 사진을 첨부합니다.
5. 확인 화면에서 내용을 검토한 뒤 제출합니다.

제출 후:

- 관리자 관리 화면의 자재누락 목록에 즉시 접수됩니다.
- 처리 상태와 이력은 관리 화면에서 확인합니다.

## 15. 관리

관리 메뉴는 관리자 수정 모드에서 주요 운영 데이터를 처리하는 화면입니다.

관리 탭:

- `작업자`
- `푸시`
- `불안전요소`
- `자재누락`

관리자 수정 모드가 꺼져 있으면 일부 목록만 볼 수 있고, 상태 변경/삭제/초기화 기능은 제한됩니다.

## 16. 관리 > 작업자 탭

작업자 탭에서는 작업자 등록 정보와 푸시 구독 상태를 관리합니다.

주요 기능:

- 작업자 추가
- 작업자 이름/팀/직책 수정
- 조장 지정 또는 작업자로 변경
- 작업자 삭제
- 작업자별 브라우저 알림 구독 상태 확인
- `알림수정`으로 해당 작업자의 등록 기기 목록 확인
- 알림 기기명 수정
- 알림 기기 활성/비활성
- 알림 기기 삭제

작업자 카드의 알림 배지는 대상자가 실제 수신 가능한 단말을 등록했는지 확인하는 기준입니다.

## 17. 관리 > 푸시 탭

푸시 탭은 관리자가 직접 작업자 단말에 브라우저 푸시를 보내는 화면입니다.

### 발송 대상

- `구독 작업자`: 알림 등록 단말이 있는 작업자만 자동 선택합니다.
- `전체 작업자`: 전체 작업자를 대상으로 선택합니다. 단, 알림 미등록자는 실제 수신되지 않습니다.
- `선택 작업자`: 작업자 카드에서 직접 선택한 작업자에게 보냅니다.

### 푸시 문구

- 제목을 입력합니다.
- 내용을 입력합니다.
- 클릭 시 이동할 화면을 선택합니다.
- 사용할 수 있는 문구 토큰:
  - `{날짜}`
  - `{발신자}`
  - `{대상수}`

### 푸시 스타일

- `일반`: 일반 표시
- `주의`: 확인 전까지 유지
- `긴급`: 확인 전까지 유지, 긴급 진동 패턴
- `완료`: 일반 표시

브라우저 푸시는 OS/브라우저 정책을 따르므로 모바일 알림의 디자인 자체를 웹페이지처럼 꾸밀 수는 없습니다. 스타일은 제목 접두어, 유지 옵션, 진동 패턴, 클릭 이동 화면에 반영됩니다.

### 발송 권한

다음 조건을 모두 만족해야 발송됩니다.

1. 관리자 수정 모드가 켜져 있어야 합니다.
2. 로그인 작업자가 조장/총무/관리 권한이어야 합니다.
3. 대상 작업자에게 알림 등록 단말이 있어야 합니다.
4. 제목과 내용이 비어 있지 않아야 합니다.

권한이 없거나 허용되지 않은 발송 종류는 서버에서 차단됩니다.

## 18. 관리 > 불안전요소 탭

불안전요소 탭에서는 접수된 위험요소를 처리합니다.

주요 기능:

- 접수 목록 확인
- 호선/상태/작업자 기준 필터
- 상태 변경
- 상세 내용과 사진 확인
- 이력 초기화
- 내보내기
- 푸시 문구 수정

불안전요소 내보내기는 사진 원본을 ZIP에 포함합니다. 내보내기 후 앱에는 썸네일 데이터만 남도록 정리됩니다.

## 19. 관리 > 자재누락 탭

자재누락 탭에서는 접수된 누락 자재를 처리합니다.

주요 기능:

- 접수 목록 확인
- 호선/상태/작업자/자재명 기준 필터
- 상태 변경
- 상세 내용과 사진 확인
- 이력 초기화

처리 상태를 최신으로 유지하면 현장 작업자와 관리자가 같은 기준으로 누락 자재 현황을 확인할 수 있습니다.

## 20. 데이터 내보내기와 불러오기

### 호선 엑셀

- 데스크톱 화면에서 호선 엑셀 내보내기/불러오기를 사용할 수 있습니다.
- 불러온 호선은 호선 화면뿐 아니라 불안전요소/자재누락 등록 화면의 호선 목록에도 반영됩니다.

### 불안전요소 내보내기

- 접수 데이터와 사진 원본을 ZIP 형태로 내보냅니다.
- 내보내기 후 앱에는 썸네일만 남기는 정리 로직이 적용됩니다.

## 21. 운영 점검 순서

매일 운영 전 권장 점검:

1. 사이트 접속 후 좌측 상태가 온라인인지 확인합니다.
2. 작업자 로그인과 사번 검증이 되는지 확인합니다.
3. 홈의 오늘 점검 수치가 현장 상황과 맞는지 확인합니다.
4. 호선 목록이 최신인지 확인합니다.
5. 작업지시서 등록 인원과 공기구가 맞는지 확인합니다.
6. 푸시가 필요한 작업자는 각자 휴대폰 알림 등록을 완료했는지 확인합니다.
7. 관리 > 푸시 탭에서 구독 작업자 수를 확인합니다.
8. 필요한 경우 테스트 알림으로 실제 수신을 확인합니다.

## 22. 문제 해결

### 화면 숫자가 다른 사람과 다르게 보이는 경우

1. 좌측 동기화 상태를 확인합니다.
2. 새로고침합니다.
3. 다른 브라우저 또는 모바일에서 같은 작업자로 로그인해 비교합니다.
4. 계속 다르면 관리자가 원격 데이터 기준으로 다시 확인합니다.

### 푸시가 오지 않는 경우

1. 대상 작업자가 해당 휴대폰에서 직접 로그인했는지 확인합니다.
2. 알림 등록 버튼을 눌러 등록 완료 상태인지 확인합니다.
3. 브라우저/OS 알림 권한이 허용인지 확인합니다.
4. 관리 > 작업자 탭에서 해당 작업자의 알림 배지를 확인합니다.
5. 관리 > 푸시 탭에서 대상자로 선택한 뒤 테스트 발송합니다.

### 관리자 버튼이 비활성화된 경우

1. 관리자 수정 모드가 켜져 있는지 확인합니다.
2. 푸시 발송 기능이면 로그인 작업자가 조장/총무/관리 권한인지 확인합니다.
3. 대상 데이터가 없거나 선택되지 않았는지 확인합니다.

### 호선 목록이 적게 보이는 경우

1. 호선 화면에서 실제 호선이 등록되어 있는지 확인합니다.
2. 관리자 수정 모드에서 호선을 추가하거나 엑셀로 불러옵니다.
3. 새로고침 후 불안전요소/자재누락 등록 화면에서 다시 확인합니다.

## 23. 운영상 주의사항

- 관리자 비밀번호와 사번은 외부 문서에 공개하지 않습니다.
- 불안전요소/자재누락 이력 초기화는 신중히 사용합니다.
- 푸시는 실제 작업자의 휴대폰에 도달할 수 있으므로 테스트 문구와 운영 문구를 구분합니다.
- 동일 작업자에게 여러 기기가 등록되어 있으면 모든 활성 기기에 푸시가 발송됩니다.
- 브라우저/OS 정책에 따라 알림 표시 모양은 기기마다 다를 수 있습니다.
